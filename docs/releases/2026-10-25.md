# 2026-10-25 迭代记录

## APP

- 支持纸质记录的冲泡量、实际量、剩余量，区分小便次数与换尿布次数；统计、编辑和 CSV 使用统一口径。
- 增加一顿奶的开始、完成、取消、撤销流程，避免把准备量立即计入摄入。
- 增加待核对队列、原话保留、重新解释与人工确认。
- 相册支持照片、视频与 Live Photo 的关联删除，保留护理事件和系统相册原件。
- 助手同步叠加云端回执，手机持久保存后确认，支持版本冲突保护。

## 小聆

- 保留原数据看板，解决小应用模式和语音护理工具的冲突。
- 云端护理入口与 Lua 读屏分离；摘要条件刷新、断网退避、设备持久缓存。
- 保留小聆名称与唤醒词，人设改为简短、温柔、按真实回执回答。
- 用户提供的两首儿歌通过私有曲库和官方音频通道播放，看板可继续显示。
- v0.1.5 修复提前打开 TTS 导致无声：有文字才开流；明确的即时奶量直接校验保存，复杂记录先回复再后台处理。
- 后续修复拍照只回答“好的”的路由回归：新增原生操作分类和强制工具调用，结果不重复执行。正常桌面下的真机拍照及设备状态查询通过；看板模式仍被固件拒绝，完整共存尚未完成。
- Agent v0.1.6 修复模式拒绝被误标成功并静默结束的问题，改为明确失败播报，保留看板。服务端测试增至 70 项，Agent 测试增至 4 项；未刷写设备固件。

## 本轮优化与开源整理

手机空心跳不再触发全量护理解析与汇总；奶量查询简短化；记录成功读回实际数量；真实域名、产品 ID 改为私密配置；增加生产 iOS 打包环境检查、管理员配对/曲库工具、CI 与完整教程。

本轮在本地完成移动端类型检查、100 项移动端测试、64 项服务端测试、Web 构建、Agent 类型与 2 项播放器/响应测试，Lua 模拟器缓存测试也通过；实体设备验证过看板、切页、语音查询、记录同步、歌曲出声和打断。最近的异步改动还通过隔离的慢解析测试，不用虚构奶量污染家庭数据。
