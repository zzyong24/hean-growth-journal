# 禾安 · 小聆桌面

适配 Arcs-Mini3 3.0.3、240×240 屏幕。保留禾安奶油底色、暖橙主色的数据看板；功能键切换今日概览与剩余奶量。助手仍叫小聆，唤醒词仍为“小聆小聆”。

## 看板、语音和曲库

- `hean.lua`：只读数据看板。每 3 秒向禾安云端检查版本，无变化仅返回小摘要；断网逐步退避到 60 秒。相同日期的持久缓存可立即显示，离线明确显示缓存状态，跨天不把昨天的数字当成今天。
- `agent/`：基于官方 Agent SDK 的语音入口。护理记录和查询经禾安服务处理，与 Lua 小应用工具隔离；家庭音频使用官方音频 URL 通道，可在看板显示时播放。原生小应用模式会限制专用音乐 MCP，因此不再调用该通道。
- `persona.txt`：温柔、简短、按真实回执回应。云端保存与手机已同步分开说明；数据查询每次读取当前云端状态。
- `standby.html` 与六张 PNG：没有载入看板时使用的禾安主题，上传到角色表情管理。全部为 240×240。

曲库仅有用户提供的《ABC儿歌》《鲁冰花》，另提供两首连播，不搜索或跳转收费曲库。当前设备没有 TF 卡，文件存放在禾安私有服务器，通过限时链接播放，**仍需联网**。唤醒小聆会打断歌曲，可以随后记录或重新点歌；未实现断点续播。

## 载入信息屏

先部署 [语音 Agent](agent/README.md)，并按 [护理路由说明](care-routing.md) 配置禾安模型入口。仅修改平台提示词不能解决原生小应用模式的工具冲突。

通过手机账号认证调用 `POST /api/voice/display-pair`，请求体为 `{"profileKey":"宝宝ID"}`。将返回的摘要地址和只读令牌保存在权限 `0600` 的私密文件：

```json
{"url":"https://你的禾安服务/api/display/summary","token":"只读配对令牌"}
```

```sh
python3 devices/xiaoling/install.py --adb /path/to/adb --credentials /private/display-link.json --serial DEVICE_SERIAL
```

安装器将令牌写入临时 Lua，通过 USB 上传后删除临时文件。不要提交凭据或已填入令牌的 Lua。看板凭据只能读取单个宝宝的摘要，不能写记录或读取原始笔记。

官方本地调试的小应用源码保存在内存中，**设备重启后需重新载入看板**；缓存保存在设备存储中，重新载入时可复用。角色表情和云端语音配置不受此次重启影响。

## 数据与缓存

云端保存手机最近同步的快照，并叠加尚未被手机确认的语音记录；手机未打开时也能记录和查询。手机恢复后合并回执。内存中的合并状态和摘要按版本缓存，真实语音写入、手机内容变化、确认回执和日期切换才会重新计算；相同快照和空心跳只更新同步时间。

云端摘要分别提供数据更新时间和手机同步时间，看板显示云端更新时间。未知值显示 `--`，剩余奶量只统计同时有冲泡量与实际奶量的记录。尚未同步的手机手动修改无法被云端提前获知。

## 验证

运行 `npm --prefix server test` 验证摘要、日期、未知值、凭据范围、幂等记录和私有音频。Agent 验证见其 README。将 `hean.lua` 与 `tests/cache.lua` 拼成临时脚本，使用官方模拟器 `lingclaw-sdk --headless test.lua screenshot.png` 验证缓存恢复、条件刷新、退避、未知值清除及跨天行为。

实体验证必须保持看板运行，检查设备实际请求、播放状态和真实保存回执，不能仅依据助手口头说“已播放/已保存”。已验证看板切页、语音查询、原记录更新与手机确认、两首歌取流和播放、唤醒打断；相关方法见[完整教程](../../docs/xiaoling-development.md)。

官方依据：[LingClaw SDK](https://github.com/LISTENAI/LingClaw-SDK)、[聆思平台](https://platform.listenai.com/)。
